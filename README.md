# Portfolio — Fanny Mallet

Portfolio sur le thème du voyage, pour présenter mon parcours, mes projets et mes compétences.

🔗 **Site en ligne** : https://malletfanny.github.io/portfolio/

## Technologies
HTML, CSS (Grid, Flexbox, responsive), JavaScript natif

## Fonctionnalités
- Onglets de compétences interactifs
- Filtrage des projets par technologie
- Cartes postales qui se retournent au survol
- Accessibilité : navigation au clavier, attributs ARIA
